# livelayer.dk

```
npm install
npm run dev      # http://localhost:5173
npm run build    # static site in dist/
```

- Copy and figures live in `content/`: `da.mjs`, `en.mjs` and `data.mjs`.
- `scripts/build-pages.mjs` generates the pages into `site/`.
- Styles are in `site/src/styles.css` and motion in `site/src/main.js`.

See CLAUDE.md, PRODUCT.md and DESIGN.md for the rules and the direction.
